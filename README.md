# 🛒 Local Digital Shop

A full-stack MERN application that connects local shopkeepers with customers through a modern digital platform.

## 📌 Features

- User Registration
- User Login (JWT Authentication)
- Password Hashing using bcrypt
- Protected Routes
- User Profile
- Product Management
- Search Products
- Shopping Cart (Coming Soon)
- Order Management (Coming Soon)
- Payment Integration (Coming Soon)

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

- JWT

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/anshikagarga/Local-Digital-Shop.git
```

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the Backend folder.

```
PORT=5000
MONGO_URL=your_mongodb_connection
JWT_SECRET=your_secret_key
```
